# Өгөгдөл

## CSV импортын формат

UTF-8, эхний мөр толгой. Загвар файлууд: `data/samples/`. Заавал баганатай мөр хоосон бол алдааны жагсаалтад орно.

| Файл | Заавал багана | Нэмэлт багана | API |
|---|---|---|---|
| CLO | `code`, `text` | — | `POST /api/versions/{id}/import?kind=clo` |
| Сургалтын элемент | `type`, `title` | `text`, `question_text` | `POST /api/versions/{id}/import?kind=item` |
| PLO | `code`, `text` | — | (А4) |
| Ажлын зарлал | `title`, `text` | `posted_date` (YYYY-MM-DD), `source` | `POST /api/programs/{id}/batches` |

`type` ∈ `lecture`, `lab`, `assignment`, `exam`.

## Нууцлал

- Бодит хөтөлбөр, хичээлийн баримт, ажлын зарлалыг **`data/private/`**-д хадгална (`.gitignore`-д орсон) — repo-д оруулахгүй.
- Ажлын зарлалаас нэр, утас, имэйлийг хадгалахаас өмнө арилгана (ФБШ-05).
- Хөтөлбөр, хичээлийн баримтыг ашиглах зөвшөөрлийг тэнхимээс авна.

## Тэмдэглэгээтэй өгөгдөл (алтан стандарт)

Бүлэг 4-ийн туршилтад ашиглана. Хоёр тэмдэглэгч **бие биеэ харалгүй** тэмдэглэнэ.

| Даалгавар | Тэмдэглэх зүйл | Утгууд | Хэмжүүр |
|---|---|---|---|
| СА3: CLO ↔ элемент | Хос бүрийн холбоо | `direct` / `partial` / `none` | P, R, F1; kappa |
| СА4: Блумын түвшин | CLO, элемент бүрийн түвшин | 1–6 | macro-F1; kappa |
| СА1: Ур чадвар | Зарлал бүрийн ур чадварын хэллэг | хэллэгийн жагсаалт | P, R, F1 |
| СА2: Хамрах хүрээ | PLO ↔ CS2023 / ур чадвар | `direct` / `partial` / `none` | kappa |

Файлын бүтэц (`data/private/annotations/`): `annotator_A.csv`, `annotator_B.csv`, эцсийн `gold.csv`.
Зөрүүтэй тохиолдлыг хамтдаа хэлэлцэж `gold.csv`-д нэгтгэнэ. Тэмдэглэх заавраа эхлээд 10–20 жишээн дээр туршиж тохиролцоно.
