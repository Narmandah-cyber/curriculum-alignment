# Жишиг өгөгдөл (seed)

| Файл | Агуулга | Төлөв |
|---|---|---|
| `bloom_verbs.csv` | Блумын түвшний монгол үйл үгийн **анхны ноорог** (`verb,level`) | Багш нартай / ШУТИС-ийн CLO бичих зааврын дагуу шалгаж засна [эх сурвалж хэрэгтэй] |
| `cs2023_units.csv` | CS2023-ийн мэдлэгийн чиглэл, нэгж (`area_code,unit_name,description`) | **Хоосон загвар.** CS2023 баримтаас гараар бөглөнө (А5). Өгөгдөл зохиож бичихгүй. |

`python -m app.seed` нь эдгээрийг өгөгдлийн санд ачаална.
